⌁LectureSnap

Turn whiteboard lectures into revision images.

Paste a permitted YouTube lecture link. In Whiteboard mode, LectureSnap saves a board only when it has been cleared or reset - adding more equations never creates an extra image.

Whiteboard mode saves the most information-rich image before each board reset - not a partially erased frame. The optional remover uses the clearest board pixels from the previous 5 seconds.
